# Jayanth Shree Vishnu — Portfolio

Personal portfolio website showcasing my work as a Software Development Engineer. Built with React + Vite, deployed on GitHub Pages.

🔗 **Live site:** [jayanthvishnu.github.io/myPortfolio](https://jayanthvishnu.github.io/myPortfolio/)

---

## About

Backend-focused SDE with experience shipping production systems for manufacturing clients — real-time dashboards, traceability apps, and machine-integration services. The portfolio covers my professional work at Cymbeline Innovation, open-source projects, and personal builds.

## Sections

- **Hero** — Name, role, summary, links, and stats
- **About** — Background, quick facts, and strengths
- **Skills** — Languages, frameworks, databases, protocols and tools
- **Experience** — 6 production projects at Cymbeline Innovation (Panasonic, HMSI, DENSO, Foxconn, etc.)
- **Projects** — QRLayout, EnvDrift, Hospital Management System, AI PDF Reader, and more
- **Contact** — Email form (Formspree) + direct contact details

## Tech Stack

| Area | Tech |
|---|---|
| Framework | React 19 + Vite 7 |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion |
| Fonts | Inter, Sora (Google Fonts) |
| Deployment | GitHub Pages via `gh-pages` |
| Form | Formspree |

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build & Deploy

```bash
npm run deploy
```

This runs `vite build` then pushes the `dist/` folder to the `gh-pages` branch.
